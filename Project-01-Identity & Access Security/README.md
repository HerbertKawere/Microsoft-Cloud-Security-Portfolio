## Project 01 - Identity & Access Security

## Overview
This project demonstrates how Microsoft Entra ID can be used to implement Zero Trust identity controls in a hybrid environment.

The solution integrates hybrid identity, secure authentication, privileged access management, and identity governance to reduce identity-related risk and strengthen access control.

## Scenario
Secure Networks Ltd. requires secure access to Microsoft 365 resources while reducing the attack surface associated with user and administrative accounts.

## Implementation

- Hybrid Identity

  Implemented synchronization between Active Directory and Microsoft Entra ID using Entra Connect.
  
- Multi-Factor Authentication (MFA)

  Configured MFA to provide additional authentication security.
  
- Conditional Access

  Created Conditional Access policies to enforce MFA and control access to cloud applications.
  
- Privileged Identity Management (PIM)

  Configured Just-In-Time and Just Enough administrative access.
  
- Access Reviews

  Implemented periodic access certification for privileged users.
  
- Entitlement Management

  Created access packages to support controlled resource requests.

## Key Takeways
- Strengthened understanding of Conditional Access policy evaluation.
- Improved knowledge of hybrid identity architecture.
- Demonstrated Just-In-Time administrative access using PIM.
- Applied Identity Governance through Access Reviews and Entitlement Management.
- Reinforced Zero Trust identity security principles.

## Technologies Used

- Active Directory- Microsoft Entra ID- Entra Connect- Multi-Factor Authentication (MFA)- Conditional Access- Privileged Identity Management (PIM)- Access Reviews- Entitlement Management
